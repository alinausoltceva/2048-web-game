# Лабораторная работа 3: 2048

Браузерная версия логической игры 2048, в которой пользователь перемещает числовые блоки по игровому полю, объединяет одинаковые значения и набирает очки. Цель игры - получить блок со значением 2048. Реализованы управление с клавиатуры и мобильных устройств, сохранение игрового состояния, отмена хода и таблица рекордов.

## О проекте

Создана интерактивная браузерная игра 2048 с игровым полем размером 4×4.

На странице представлены:

- игровое поле с числовыми блоками;
- текущий счёт;
- лучший результат;
- кнопка начала новой игры;
- кнопка отмены последнего хода;
- кнопка просмотра таблицы рекордов;
- окно окончания игры с возможностью сохранить результат.

В начале игры на поле случайным образом появляются от одной до трёх плиток со значениями 2 или 4.

## Игровая механика

Игрок может перемещать блоки в четырёх направлениях: вверх, вниз, влево и вправо.

При перемещении блоки сдвигаются в выбранную сторону. Если два блока с одинаковыми значениями сталкиваются, они объединяются в один блок с удвоенным значением. За каждое слияние начисляются очки.

После каждого успешного хода на свободных клетках случайным образом появляются новые блоки со значениями 2 или 4.

Один блок может участвовать только в одном слиянии за ход. Игра продолжается до тех пор, пока на поле остаются возможные перемещения. Если свободных клеток нет и соседние блоки невозможно объединить, игра заканчивается.

## Система очков

За каждое слияние игрок получает количество очков, равное значению нового блока. Текущий счёт отображается в верхней части игрового интерфейса. Также реализовано сохранение лучшего результата. Он обновляется автоматически, если текущий счёт превышает предыдущий рекорд.

## Управление

Управление игрой реализовано несколькими способами:

- клавиши со стрелками на клавиатуре;
- экранные кнопки направлений на планшетах и мобильных устройствах.

Дополнительно предусмотрена отмена последнего хода, которая позволяет восстановить предыдущее состояние игрового поля и вернуть прежнее количество очков. За один раз можно отменить только один ход. Кнопка "Новая игра" позволяет начать игру заново.

## Сохранение игрового состояния

Для сохранения данных используется `localStorage`. После каждого успешного хода сохраняются:

- расположение блоков на игровом поле;
- текущий счёт;
- состояние окончания игры;
- данные для отмены последнего хода.

При повторном открытии страницы игра восстанавливается с момента последнего сохранения. Лучший результат и таблица рекордов также сохраняются отдельно.

## Таблица рекордов

В игре реализована таблица десяти лучших результатов. После окончания игры пользователь может ввести своё имя и сохранить результат. В таблице отображаются:

- место в рейтинге;
- имя игрока;
- набранные очки;
- дата достижения результата.

Результаты сортируются по убыванию количества очков. В таблице сохраняются десять лучших записей.

## Анимации

Для повышения наглядности игрового процесса реализованы CSS- и JavaScript-анимации.

Предусмотрены:

- плавное перемещение блоков между клетками игрового поля;
- увеличение и уменьшение блока при слиянии;
- анимация появления новых блоков.

Для перемещения используется подход FLIP, позволяющий анимировать переход блоков из исходных позиций в конечные без изменения структуры игрового поля.

## Адаптивный интерфейс

Игровой интерфейс адаптирован для различных размеров экрана. Поддерживаются:

- компьютеры и ноутбуки;
- планшеты;
- мобильные устройства.


## Технологии

Проект реализован с использованием HTML5, CSS3 и JavaScript без сторонних фреймворков.

Для создания игрового поля и управления блоками используется JavaScript DOM API. Игровое состояние, лучший результат и таблица рекордов сохраняются с помощью `localStorage`. Для построения интерфейса применяются Flexbox и CSS Grid, для адаптивной верстки — CSS Media Queries, для анимации — CSS Animations и Web Animations API.
